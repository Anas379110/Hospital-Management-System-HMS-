# SDLC.md — نموذج دورة حياة التطوير المعتمد

## النموذج المختار
**Incremental Development مع ممارسات Agile خفيفة (Lightweight Agile/Kanban)**

## سبب الاختيار
- المشروع كبير النطاق (مشفى 10,000+ مريض) لكن ينفَّذ بفريق يعمل مع AI Agents — تسليم تدريجي بوحدات وظيفية (Patients → Appointments → EMR → Pharmacy → Lab → Billing) يقلل المخاطر ويتيح تسليم قيمة حقيقية مبكراً (MVP قابل للاستخدام في قسم استقبال واحد قبل اكتمال كل الوحدات).
- لا يوجد جدول زمني ثابت أو ضغط عميل خارجي يفرض Sprints زمنية صارمة (لا فائدة حقيقية من طقوس Scrum الكاملة كـ Sprint مغلق بأسبوعين).
- Kanban (لوحة مهام بحد أقصى للعمل الجاري) أنسب من Scrum الصارم لفريق صغير يعمل بمرونة مع أدوات AI، دون التزام باجتماعات دورية ثابتة.
- طبيعة القطاع الصحي تتطلب تغذية راجعة متكررة من مستخدمين حقيقيين (أطباء/ممرضين) أثناء البناء — يستبعد هذا Waterfall الصارم.

## البدائل المرفوضة
| النموذج | سبب الرفض |
|---|---|
| Waterfall | المتطلبات الصحية التفصيلية (خاصة الصيدلية/المختبر) ستتضح تدريجياً من تجربة الاستخدام الفعلي — الجمود غير مناسب |
| V-Model | تكلفة تخطيط زائدة لا تناسب فريقاً صغيراً بلا جدول زمني ضاغط |
| Scrum الكامل | طقوس زمنية ثابتة (Sprints، Standups يومية) غير ضرورية لفريق صغير بلا التزامات خارجية بمواعيد |
| Spiral | مصمم لمشاريع عالية المخاطر المالية الضخمة — نطاقنا أصغر وأبسط من ذلك حالياً |

## طريقة إدارة التغيير
- كل EPIC/Feature جديدة تُقيَّم عبر Impact Analysis (محدد في `SCOPE.md`) قبل إضافتها.
- التسليم يكون بوحدات وظيفية كاملة (Vertical Slices): كل وحدة تشمل Database + API + UI + Tests قبل الانتقال للوحدة التالية، بدل بناء كل الطبقات لكل الوحدات دفعة واحدة.
- لوحة Kanban في `TASKS.md` (EPIC → Feature → Task → Subtask) هي مصدر تتبع التقدم الوحيد.

## ترتيب تسليم الوحدات (Incremental Slices)
1. Core: مستخدمون + صلاحيات + مرضى (MVP الأساسي) — **مكتمل (Slice 1)**
2. EMR أساسي (تشخيص، وصفة، ملاحظات) — **مكتمل (Slice 2)**
3. المواعيد (Appointments) — **التالي (Slice 3)** — نُقلت من الخطوة 1 الأصلية بعد ملاحظة أن EMR لا يعتمد بالضرورة على وجود موعد مسبق (appointmentId اختياري بالفعل بالمخطط)، فبدأنا بالأصغر تسليماً أولاً
4. الأقسام والأسرّة (Slice 4)
5. الصيدلية والمخزون
6. المختبر والأشعة
7. الفوترة والتأمين
8. التقارير + توسعة FHIR (MLP)
