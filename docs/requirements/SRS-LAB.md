# SRS-LAB.md — متطلبات Slice 6 (MMP)

## Functional Requirements

### FR-7: Lab/Radiology Module
- FR-7.1: الطبيب يطلب فحصاً (مختبر أو أشعة) مرتبطاً بزيارة (Encounter) قائمة
- FR-7.2: الفني (مختبر/أشعة) يرى قائمة الفحوصات المعلَّقة
- FR-7.3: الفني يُدخل النتيجة (نص/قيم) ويُعلِّم الطلب "مكتمل"
- FR-7.4: الطبيب/الممرض يرى نتائج الفحوصات ضمن السجل الطبي للمريض

## القرارات الجديدة

**Decision 016 — دور فني واحد موحَّد للمختبر والأشعة**
بدل دورين منفصلين (`lab_tech` و`radiology_tech`)، دور واحد `lab_tech` يغطي كليهما — يطابق واقع المشافي الصغيرة/المتوسطة حيث غالباً يتشارك الفنيون العمل، ويتجنَّب تعقيد صلاحيات غير مبرَّر بحجم النظام الحالي (قاعدة عدم الإفراط بالهندسة). يمكن فصلهما مستقبلاً بسهولة (Expand) لو احتاج المشفى فعلياً لذلك. Status: CONFIRMED

**Decision 017 — الفحص مرتبط إلزامياً بزيارة (Encounter)**
بعكس الوصفة (Prescription) التي تُصرف بشكل شبه مستقل، طلب الفحص يبقى مرتبطاً دائماً بزيارة طبية محدَّدة — يضمن سياقاً سريرياً واضحاً لكل نتيجة عند المراجعة لاحقاً. Status: CONFIRMED

## User Stories

**US-8 (Doctor):** كـ طبيب، أريد طلب فحص مختبر أو أشعة أثناء الزيارة، حتى أحصل على بيانات تشخيصية إضافية.
**Acceptance:** الطلب يظهر فوراً بقائمة الفني المختص، مرتبطاً بالزيارة والمريض.

**US-9 (Lab Technician):** كـ فني مختبر، أريد رؤية كل الطلبات المعلَّقة، حتى لا يفوتني تنفيذ أي فحص.
**Acceptance:** القائمة مرتبة من الأقدم للأحدث، تعرض اسم المريض ونوع الفحص والطبيب الطالب.

**US-10 (Doctor):** كـ طبيب، أريد رؤية نتيجة الفحص فور اكتمالها ضمن سجل المريض، حتى أكمل التشخيص والعلاج.
**Acceptance:** النتيجة تظهر بنفس شاشة السجل الطبي الموجودة أصلاً (لا شاشة منفصلة يبحث عنها الطبيب).
