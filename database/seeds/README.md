# database/seeds/README.md

بيانات البذر الأولية للتطوير والاختبار فقط — لا بيانات مرضى حقيقية إطلاقاً.

## المحتوى المطلوب عند التنفيذ الفعلي (Development Phase)
1. مستخدم Admin افتراضي واحد (username: `admin`, كلمة مرور مؤقتة تُغيَّر إلزامياً عند أول دخول).
2. 3 أقسام تجريبية: باطنية، جراحة، طوارئ — بعدد أسرّة صغير (5 لكل قسم) للاختبار.
3. مستخدم تجريبي واحد لكل دور (طبيب، ممرض، استقبال، مدير) لأغراض QA فقط — يُحذف قبل Production.

سيُنفَّذ عبر `prisma/seed.ts` وقت مرحلة Development الفعلية — هذا الملف مرجعي تخطيطي فقط ضمن Gate 5.
