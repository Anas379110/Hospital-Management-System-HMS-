# Hospital Management System (HMS)
**Hospital Management System (HMS)** · Classification: System / Application
> Project overview and scope; this repository contains documentation only, not implementation source code.

## Project Overview
A comprehensive platform to manage a hospital with capacity for more than 10,000 patients, covering 11 units and 8 user roles, Arabic/English.

## Highlights
- Modular Monolith (NestJS + PostgreSQL + Prisma) covering reception, medical record, pharmacy, laboratory, and billing
- Role-Based Access Control (RBAC) across 8 different user roles
- Resilient-by-default design that operates reliably despite power and internet fluctuations

## Role
Design and development of hospital management modules and interfaces, taking into account different roles, local operational requirements, and bilingual support.

## Technologies Used
NestJS, TypeScript, PostgreSQL, Prisma, React, JWT
